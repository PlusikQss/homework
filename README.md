                 # Проект: обработка банковских операций

Учебный проект по Python: маскировка номеров карт/счетов, виджет банковских операций, работа с данными.

## Структура проекта

- `src/masks` — функции маскирования номеров карт и счетов.
- `src/widget` — виджет и вспомогательные функции (маскирование по типу, обработка дат).
- `tests` — тесты на `pytest`, фикстуры, параметризация.
- `htmlcov` — отчёт о покрытии кода тестами.

## Тестирование

Тесты написаны на `pytest`, используются фикстуры и параметризация для покрытия разных кейсов. Покрытие кода тестами > 80 %.

Запуск всех тестов:
```bash
poetry run pytest
